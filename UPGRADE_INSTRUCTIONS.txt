PASIG CITY HALL PORTAL — REPLACEMENT FILE UPGRADE

ROLE ANNOUNCEMENTS UPGRADE
--------------------------
For an existing installation, run this migration in phpMyAdmin before opening the upgraded portal:

  database/migrations/003_announcements_and_retention.sql

It adds announcement sender and expiry fields to notifications. Fresh installations already receive these fields from database/schema.sql.
FOR YOUR EXISTING PORTAL/DATABASE (preserves current data)

1. Back up first:
   - Rename/copy your existing folder.
   - In phpMyAdmin, export the database pasig_feedback_portal.

2. Extract the replacement-files ZIP directly into:
   C:\xampp\htdocs\pasig-cityhall-feedback-portal
   Choose “Replace the files in the destination.”

3. DO NOT import database\schema.sql into an existing database because it is for a fresh install and recreates tables.

4. In phpMyAdmin, import this file ONCE only:
   database\migrations\002_workflow_security_upgrade.sql

5. Confirm config\app.php uses this Python executable:
   C:/Users/PC/AppData/Local/Programs/Python/Python312/python.exe

6. Restart Apache in XAMPP, sign in, then open:
   Administrator > System & Audit
   The SVM Bridge card must show “Working.”

7. Optional automated check:
   Double-click tests\run_smoke_test.bat

FRESH INSTALL ONLY
Import database\schema.sql, then use the included demo accounts.

BACKUP/RESTORE
Administrator > System & Audit > Download SQL Backup creates a full .sql backup.
Restore through phpMyAdmin Import into pasig_feedback_portal.

IMPORTANT
- Run the upgrade migration once only. Re-running it will report duplicate-column/constraint errors.
- The included 300-comment SVM model and 81.67% holdout result are development/demo evidence.
- Final research results still require an approved, de-identified, manually labeled CHD dataset and formal evaluation.
