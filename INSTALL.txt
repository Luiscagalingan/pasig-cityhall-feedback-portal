PASIG CITY HALL SERVICE SATISFACTION MONITORING SYSTEM

FRESH INSTALL
1. Copy the folder to C:\xampp\htdocs\pasig-cityhall-feedback-portal
2. Start Apache and MySQL.
3. Import database\schema.sql through phpMyAdmin.
4. Confirm config\app.php uses:
   C:/Users/PC/AppData/Local/Programs/Python/Python312/python.exe
5. Open http://localhost/pasig-cityhall-feedback-portal/

UPGRADE FROM THE PREVIOUS PORTAL
1. Back up the existing folder/database.
2. Replace all project files.
3. Import database\migrations\002_workflow_security_upgrade.sql ONCE.
4. Restart Apache.
5. Run tests\run_smoke_test.bat.
